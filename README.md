| Платформа | Формат пакета | Описание |
| :--- | :--- | :--- |

| 🍎 **iOS (Apple)** | Xcode Workspace (`packages/mobile/ios`) | Сборка для iPhone & iPad через Capacitor |

## 🌟 Ключевые возможности

### 1. 🕸️ Интерактивный Нейро-Граф знаний
- **Органическая D3-симуляция**: Живые синапсы, бегущие электрические импульсы и силовые связи между мыслями.
- **Готовые пресеты физики**:
  - ⚡ **Базовый**: Сбалансированное распределение.
  - 🔗 **Кластер**: Плотная группировка по темам и папкам.
  - 🪐 **Космос**: Просторные связи для масштабных баз знаний.
  - ⚛️ **Ядро**: Высокая гравитация с акцентом на центральные хабы.
- **Вики-ссылки `[[WikiLinks]]`**: Создание и связывание заметок в 1 клик с автодополнением и подсчетом обратных ссылок (Backlinks).

### 2. 🎨 Бесконечный визуальный Холст (Visual Canvas)
- Размещение заметок, стикеров и карточек на бесконечной плоскости.
- Соединение карточек направленными стрелками в 2 клика.
- Плавное панорамирование и мультитач-зум.

### 3. 📅 Умный Календарь смен и Планировщик дел
- **Готовые рабочие циклы**: 1/1, 2/2, 1/3, 5/2, суточные, дневные и ночные смены.
- **Конструктор своего графика**: Составление произвольной последовательности рабочих дней и выходных.
- **Финансовый расчет**: Автоматический подсчет начисленной зарплаты по почасовой или фиксированной ставке.
- **Личные события**: Планирование стрижек, тренировок, врачей и важных встреч.

### 4. 💰 Личные финансы, Бюджет и Накопления
- **Интерактивные графики**: Сенсорный анализ доходов, расходов и чистого сальдо по дням и месяцам.
- **Категории трат**: Контроль главных статей расходов и процента сбережений (Savings Rate).
- **Копилки и Цели**: Визуальный прогресс-бар накоплений на цели и депозиты с капитализацией процентов.

### 5. 📝 Редактор документов Word / Markdown
- Редактор с поддержкой Markdown, формул, списков задач и таблиц.
- Строка итогов в таблицах с автоматическим подсчетом сумм (`SUM`, `AVG`, `COUNT`).
- 100% локальное хранение данных в формате `.md` файлов в папке пользователя.

### 6. ⚡ Офлайн P2P Синхронизация (Wi-Fi & Bluetooth)
- Прямой обмен заметками между компьютером и телефоном по локальной сети без серверов, облаков и подписок.
- Ваши данные никогда не покидают ваши персональные устройства.

## 🖥️ Сборка из исходников

### Требования:
- **Node.js**: 18.0+ (рекомендуется 20 LTS или 24)
- **npm**: 10.0+
- **Java JDK 17+** (для сборки Android APK)
- **Android SDK / Command-line Tools** (для сборки Android APK)

### 1. Клонирование и установка зависимостей:
```bash
git clone https://github.com/your-username/NeironoBoock.git
cd NeironoBoock
npm install
```

### 2. Запуск в режиме разработки:
```bash
# ПК версия (Electron + Vite):
npm run start

# Мобильная версия (Web preview):
npm run dev:mobile
```

### 3. Сборка готовых дистрибутивов:

#### 🪟 Windows (.exe):
```bash
npm run build:desktop:win
```

#### 🐧 Linux (.AppImage, .deb):
```bash
npm run build:desktop:linux
```

#### 🍏 macOS (.dmg):
```bash
npm run build:desktop:mac
```

#### 📱 Android (.apk):
```bash
npm run build:apk
```
*Готовый подписанный APK будет сохранен в корень проекта: `NyronNotebook.apk`.*

## ⌨️ Горячие клавиши (Desktop)

| Комбинация | Действие |
| :--- | :--- |
| `Ctrl + K` / `Ctrl + P` | Быстрый поиск Spotlight по всей базе знаний |
| `Ctrl + N` | Создать новую заметку |
| `Ctrl + G` | Открыть интерактивный Нейро-Граф |
| `Ctrl + B` | Показать / скрыть левое дерево файлов |
| `Ctrl + \` | Показать / скрыть правую панель связей и графа |
| `Ctrl + ,` | Открыть панель настроек |
| `Ctrl + S` | Мгновенное сохранение |
| `Ctrl + W` | Закрыть текущую вкладку |
