# 🧠 Релиз NeyroNetbook v1.2.0 — Grand Multiplatform Release

Официальный стабильный релиз кроссплатформенного нейро-блокнота **NeyroNetbook (НейроноБлокнот) v1.2.0 Pro**.

---

## 🌟 Что нового в версии 1.2.0:

### 1. ⚡ Прямая P2P LAN Синхронизация (Wi-Fi / Hotspot / Bluetooth)
- Мгновенный обмен и слияние базы знаний, заметок, смен и финансовых данных напрямую между Desktop (ПК) и Mobile (Android / iOS).
- Полная автономность: работает в локальной сети, через точку доступа телефона или Bluetooth без доступа к глобальному интернету и без внешних облачных серверов.
- Безопасное сопряжение с автоматическим обнаружением устройств в сети (`/api/sync/ping`).

### 2. 🛡️ Вечное Хранилище (Eternal Vault Persistence)
- Главное состояние приложения сохраняется в `vault_state.json` с версионированием.
- Параллельный автоматический экспорт каждой заметки в чистый Markdown `.md` с сохранением заголовков, тегов и связей.
- Защита базы знаний при переустановке или обновлении операционной системы.

### 3. 📊 Глубокая Аналитика, Финансовый Инспектор и Календарь Смен
- **Двойной тап по дню календаря**: моментальное открытие модального окна детального редактирования смены.
- **Инспектор заработка в свободном пространстве**: интеллектуальное использование свободного места на экране для мгновенного отображения заработка за смену, переработок, ночных часов и итоговой суммы.
- Полный редизайн мобильного учета финансов: наглядная статистика, категории, балансы и цели накоплений.

### 4. 🌍 Кроссплатформенность и Поддержка Всех ОС
- **🪟 Windows 10 / 11**: Портативный исполняемый файл `.exe` (не требует установки) и полный `.zip` архив.
- **🤖 Android**: Подписанный релизный пакет `.apk` с поддержкой Android 8.0 — Android 15+.
- **🐧 Linux**: Поддержка дистрибутивов Ubuntu, Debian, Fedora, Arch Linux через форматы `.AppImage`, `.deb` и `.tar.gz`.
- **🍎 Apple iOS**: Полностью скомпилированный и синхронизированный проект Capacitor iOS для компиляции и установки через Xcode на iPhone и iPad.
- **🍏 macOS**: Поддержка архитектур Apple Silicon (M1/M2/M3/M4) и Intel x64 (`.dmg` и `.zip`).

### 5. 🎨 Версия 1.2.0 Pro в интерфейсе
- Обновлены все метаданные, бейджи в окне "О программе", заголовки и манифесты.
- Оптимизированы цветовые темы: глубокая темная (Cyber / Midnight), чистая светлая и автоматическая адаптация под ОС.

## 🛠️ Инструкции по сборке из исходного кода:

```bash
# 1. Установка зависимостей:
npm install

# 2. Сборка общих модулей:
npm run build:shared

# 3. Сборка для Windows:
npm run build:desktop:win

# 4. Сборка для Android:
npm run build:apk

# 5. Сборка для Linux:
npm run build:linux

# 6. Подготовка и открытие для iOS:
npm run build:ios
npm run open:ios
```
